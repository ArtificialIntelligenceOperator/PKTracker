# Подключение рума к PKTracker

Работай строго по шагам, не забегая вперёд: парсер без зелёных инвариантов бесполезен, а ошибка в нём отравляет
всю статистику.

## 1. Разведка формата (обязательно, до кода)

```powershell
python tools/scan_lines.py "<папка с историей>" --all
```

Прочитай **весь** список видов строк, особенно редкие в конце: там живут ловушки. Выпиши, как в этом руме выглядят:
начало раздачи, шапка стола, места, посты блайндов и анте, действия, вскрытие карт, доски, итоговая секция,
банк с рейком, возврат непоколлированной ставки, сайд-поты, Run It Twice (если есть).

Сверься со списком ловушек WPN в `PLAN.md` §0.6 — большинство повторяется в других румах в другом виде.

## 2. Парсер

Создай `src/PKTracker.Parsers/<Room>/<Room>HandParser.cs`, реализуй `IHandHistoryParser`. Ориентир — `WpnHandParser`.

Жёсткие правила (см. `CLAUDE.md`): суммы `long` в сотых через `decimal` + `InvariantCulture`; время `ParseExact`
с `AssumeUniversal`; ник — самым длинным совпадением из списка мест с проверкой глагола; неизвестная строка отклоняет
раздачу; кто раздан — из итоговой секции; `raises X to Y` — брать `Y`.

Если тип игры (кеш / MTT / SNG) не отличим в тексте раздачи — определяй его из имени файла отдельным `*FileNameParser`.

## 3. Инварианты на корпусе

```powershell
dotnet run --project src/PKTracker.Cli -- verify "<папка с историей>"
```

Цель: `Ошибок парсера: 0`, `Нарушений инв.: 0`. Любая ошибка — это либо непонятая строка формата, либо неверная
логика денег/позиций. Не «обходи» ошибку исключением: разберись, что означает строка.

## 4. Тесты

В `tests/PKTracker.Tests`: несколько раздач-образцов прямо в коде (как `SampleHands.cs`) с ловушками этого рума,
проверка отклонения неизвестной строки, прогон корпуса с инвариантами (пропускается, если корпуса нет).
Файлы истории в репозиторий не добавляй — там чужие ники.

## 5. Регистрация

Новая миграция `src/PKTracker.Data/Migrations/NNN_*.sql` с `INSERT INTO room`, код рума в выпадающем списке настроек.
Старые миграции не редактируются.

## 6. Проверка целиком

```powershell
dotnet test tests/PKTracker.Tests
dotnet run --project src/PKTracker.Cli -- import --conn "<строка>" --hero <ник> "<папка>"
dotnet run --project src/PKTracker.Cli -- check-agg
```

Подробности и чек-лист — `docs/ADDING_A_ROOM.md`.
