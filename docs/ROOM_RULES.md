# Правила румов и что разрешено показывать в HUD

Трекер (импорт, отчёты, реплеер, ликфайндер) разрешён во всех поддержанных румах. Ограничения касаются
**оверлея HUD во время игры**. Ниже — выжимка официальных текстов на 10.11.2026; правила меняются без
предупреждения, проверяйте их сами перед игрой. Ответственность за соблюдение — на игроке.

## Что PKTracker делает по умолчанию везде

- статы только из **своих** раздач: файл без Hero отклоняется целиком; нет датамайнинга, обмена базами,
  покупных историй;
- никакой информации о **текущей** раздаче: ни шансов банка, ни аутов, ни эквити, ни советов; `.data`-канал
  клиента используется только для рассадки;
- нет скриптов рассадки и выбора столов, нет действий за игрока, нет вмешательства в клиент (окна HUD —
  отдельные прозрачные окна поверх стола, клиент не изменяется);
- вкладки панели (P / B / C / V…) переключаются **только кликом** — «динамического» HUD, который сам
  меняет статы по ходу раздачи, нет;
- цветовые метки ставятся **только вручную** — автоматических меток по статам нет.
- виджет сессии показывает только итог **завершённых** раздач (сколько сыграно, результат в bb) — о текущей
  раздаче в нём ничего нет;
- раскладка подбирается по **размеру стола** (9max / 6max), а не по ходу раздачи: за раздачу он не меняется;
- в попапе стата матрица вскрытых рук, диаграмма силы руки и карты в списке раздач показываются за столом
  только там, где рум это допускает; на румах со «статичным» HUD они видны в реплеере и во вкладке «Игроки»;

## По румам

| Рум | HUD за столом | Дополнительно в PKTracker | Источник |
|---|---|---|---|
| **WPN** (ACR, PokerKing, Black Chip, True Poker) | разрешён: числовые статы по своим раздачам (п. 4.1.3) | — | acrpoker.eu/security, External Assistance Tools: запрещены RTA, солверы/ICM вживую, сведения о текущей раздаче (10.3), сбор чужих раздач и скрипты рассадки (4.2.7, 4.2.10) |
| **iPoker** | разрешён только **статичный** HUD | за столом в попапе стата скрыты диапазоны по вскрытым картам | redstarpoker.eu/play_poker/prohibited_software: запрещены позиционный и динамический HUD, диаграммы, статы по известным картам, автометки, значки |
| **Winamax** | разрешена личная статистика по собранным самим игроком данным | то же, что iPoker | Регламент покера Winamax от 31.01.2023, п. 1.2: запрещены солверы, ICM/эквити-калькуляторы, «динамические» диапазоны, скрипты рассадки; прочие программы — по согласованию с integrity@winamax.com |
| **PokerStars** | статичный HUD | то же, что iPoker | политика PokerStars в отношении сторонних инструментов |
| **888poker** | статистика по своим раздачам | то же, что iPoker | — |
| **GGPoker / PokerOK** | **запрещён** (есть встроенный Smart HUD) | оверлей не запускается; импорт и анализ работают | правила GG о сторонних программах |

В коде это `PKTracker.Data.RoomHudPolicy`: `HudAllowed` выключает оверлей, `StaticOnly` скрывает
за столом диапазоны по вскрытым картам. В реплеере и во вкладке «Игроки» (разбор после игры) показывается всё.
Активный рум и краткое правило видны в «Настройки → Рум».

Анонимные столы, fast-fold, Spin/Twister в официальных текстах не описаны — считайте, что HUD там
не разрешён, пока рум не подтвердит обратное.
