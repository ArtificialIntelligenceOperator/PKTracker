# Claude + ваша база PKTracker (MCP)

`PKTracker.Mcp` — MCP-сервер, через который Claude (Desktop, Code или любой MCP-клиент) работает с вашей **локальной**
базой: разбирает сыгранные раздачи, ищет лики, создаёт статы, настраивает HUD, импортирует историю.

Сервер запускается на вашем компьютере и общается с клиентом по stdio. Наружу он ничего не открывает: в облако уходит
только то, что агент явно запросил и показал в переписке.

## Установка

```powershell
dotnet build PKTracker.sln -c Release
# путь к серверу:
#   src\PKTracker.Mcp\bin\Release\net10.0\pktracker-mcp.exe
```

Проверка без клиента:

```powershell
python tools\mcp_smoke_test.py src\PKTracker.Mcp\bin\Release\net10.0\pktracker-mcp.exe
```

### Claude Desktop

`%APPDATA%\Claude\claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "pktracker": {
      "command": "C:\\путь\\к\\PKTracker\\src\\PKTracker.Mcp\\bin\\Release\\net10.0\\pktracker-mcp.exe",
      "args": []
    }
  }
}
```

Перезапустите Claude Desktop — в меню инструментов появится **pktracker**, а в меню «+» — готовые сценарии
(«Найти мои лики», «Разбор сессии», «Разбор раздачи», «Создать свой стат»).

### Claude Code

В корне репозитория лежит `.mcp.json` — Claude Code подхватит сервер автоматически, если собрать Release-сборку.
Либо разово:

```powershell
claude mcp add pktracker -- "C:\путь\...\pktracker-mcp.exe"
```

### Аргументы и переменные окружения

| Аргумент | Переменная | Смысл |
|---|---|---|
| `--conn "Host=...;Database=..."` | `PKTRACKER_CONNECTION` | строка подключения (по умолчанию из `settings.json`) |
| `--room ACR` | `PKTRACKER_ROOM` | рум: POKERKING, ACR, BLACKCHIP, TRUEPOKER |
| `--read-only` / `--allow-writes` | | запретить/разрешить изменения |
| `--anonymize` / `--no-anonymize` | | скрывать ники оппонентов или нет |

## Приватность

По умолчанию ники оппонентов заменяются псевдонимами `Villain_XXXXXX` — в ответах инструментов, в тексте раздач и даже
в результатах `run_sql`. Псевдоним стабилен на одной установке (локальная соль в `%APPDATA%\PKTracker\mcp_salt.bin`),
поэтому агент может отслеживать игрока между запросами, не зная настоящего ника. Ваши собственные ники не скрываются.

Выключить: `McpAnonymizeOpponents: false` в `settings.json` или `--no-anonymize`.
Запретить любые изменения: `McpAllowWrites: false` или `--read-only`.

Учтите: всё, что агент прочитал, попадает в облако модели — как и любой текст, который вы отправляете в чат.

## Инструменты

**Чтение**

| Инструмент | Что делает |
|---|---|
| `tracker_status` | рум, ваши ники, объём базы, режимы приватности |
| `get_overview` | winrate, bb/100, All-in EV, VPIP/PFR, часы, разбивки по позициям и лимитам |
| `list_sessions` | кеш-сессии |
| `list_tournaments` | турниры, ROI, Chip EV, $EV |
| `search_hands` | поиск рук выражением на языке статов |
| `get_hand` | раздача целиком: игроки, действия в bb, доски, исходный текст |
| `find_players` | игроки по числу рук |
| `get_player_stats` | все статы игрока с выборкой |
| `get_stat_details` | попап стата: позиции, Next Actions, сайзинги, сила руки, борды, показанные руки |
| `find_leaks` | вы против пула, сортировка по значимости |
| `run_sql` | произвольный SELECT (READ ONLY, таймаут 20 с, до 2000 строк) |
| `get_database_schema` | схема базы и единицы измерения |
| `list_stat_definitions` | все определения статов |
| `get_hud_profile` | текущий профиль HUD |

**Изменения** (можно запретить)

| Инструмент | Что делает |
|---|---|
| `test_stat` | компилирует и прогоняет стат по последним раздачам |
| `save_stat` | сохраняет стат и пересчитывает только его |
| `disable_stat` | отключает пользовательский стат |
| `set_hud_profile` | задаёт статы панели HUD |
| `add_hero_account` | добавляет ваш ник |
| `import_hand_histories` | импортирует папку с историей |

Изменения подхватываются запущенным приложением автоматически (через `reload.signal`), перезапуск не нужен.

**Ресурсы:** `pktracker://docs/stats` (язык статов), `pktracker://docs/database` (схема).

## Примеры запросов

- «Посмотри мой винрейт за последний месяц и найди три главных лика».
- «Найди все руки, где я поставил 3-бет с блайндов и проиграл больше 20bb».
- «Сделай стат "чек-рейз тёрна после колла сибета на флопе", проверь и добавь в HUD для кеша».
- «Разбери раздачу 2825662561 по улицам с учётом статов оппонентов».
- «Через run_sql посчитай мой винрейт по дням недели и часам».

## Чего сервер не делает

- **Не советует по текущей раздаче.** RTA запрещены правилами румов; инструментов для живой раздачи нет, `.data`-канал
  используется только для рассадки HUD.
- **Не отдаёт чужие базы.** Работает только с локальной базой пользователя, где по правилам рума лежат лишь его раздачи.
